30-second install

One tiny file. Nothing else to maintain.

Rackdeck compiles the server, web dashboard, and local SQLite database into one 4.8 MB Rust binary. Install it once and you're done.

1

Install Rackdeck

Run the one-line installer on Linux or macOS. No Node.js, no Python venv, and no external Postgres container to keep alive.

2

Open the dashboard

Start the server with your password and open it in your browser. Local containers, GPUs, and Tailscale peers show up right away.

3

Link your other machines

Paste a single join command on your GPU rig, Mac, or VPS over LAN or Tailscale — everything shows up in one dashboard right away.

Straight answers

Common questions.

Do I have to open ports on my home router?

Never. On home Wi-Fi or Tailscale, Rackdeck stays completely private on your network. If you use Rackdeck Connect, your machine makes a secure outbound connection so your router firewall stays closed.

Why will hosted Connect links use *.rackdev.app instead of rackdeck.dev?

Security isolation. Keeping personal remote dashboards on a separate domain (yourname.rackdev.app) prevents browser cookies and sessions from ever crossing over with rackdeck.dev.

Does it combine my Mac and NVIDIA GPU memory into one GPU?

No — each machine reports its own NVIDIA VRAM or Apple Silicon unified memory accurately. Rackdeck lets you see and manage both in one clean place rather than faking pooled memory.

Is it really open source, and does it phone home?

Yes. The entire control panel and Connect relay are Apache-2.0 on GitHub with zero product telemetry. If you don't turn on Connect, Rackdeck never contacts our servers at all.
