Quick setup

One ~6 MB file. Nothing else to maintain.

Rackdeck bundles the server, web dashboard, and SQLite storage into one ~6 MB Rust binary using about 13 MB of RAM. Prebuilt for macOS (Apple Silicon) and Linux (x86_64), with Windows supported through WSL.

1

Install Rackdeck

Run the one-line installer on macOS (Apple Silicon), Linux (x86_64), or Windows through WSL. SQLite is included. Nothing else has to be running.

2

Open the dashboard

Start the server with your password and open it in your browser. Local containers and GPU stats appear automatically.

3

Link your other machines

Use the dashboard's + Add machine button to copy a one-time join command for your other machines over LAN or Tailscale. Machines connect out, so you open zero ports.

Quick start · macOS (Apple Silicon), Linux (x86_64), Windows via WSL
# Install and start the dashboard
$curl -fsSL https://get.rackdeck.dev | sh
$RACKDECK_PASSWORD=your-password rackdeck
Dashboard listening on http://127.0.0.1:7420
# Join another machine (the dashboard's + Add machine button gives you this command)
$curl -fsSL https://get.rackdeck.dev | sh -s -- --controller <addresses> --join rd_join_… --key <key>

Straight answers

Common questions.

Do I have to open ports on my home router?

No. On home Wi-Fi or Tailscale, Rackdeck stays on your private network. Joined machines connect out to the dashboard, and Rackdeck Cloud will also use outbound encrypted connections.

Which platforms are supported today?

Prebuilt downloads are available for macOS (Apple Silicon) and Linux (x86_64), and Windows works through WSL with systemd enabled. Linux arm64 builds from source but isn't tested yet, and there's no prebuilt download.

Does it combine my Mac and NVIDIA GPU memory into one GPU?

No. Each machine reports its own NVIDIA VRAM or Apple Silicon unified memory accurately so you can see both in one dashboard.

Is it really open source, and does it send analytics?

Yes, Rackdeck is Apache-2.0 on GitHub and sends zero product analytics. Read the full architecture and threat model in our security doc.
